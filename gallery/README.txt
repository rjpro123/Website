Drop job photos here using lowercase names without hyphens, then add an entry to GALLERY_PHOTOS in js/previewwindow.js:

  {
    src: "gallery/yourphoto.jpg",
    thumb: "gallery/yourphoto.jpg",
    alt: "Job description in Suburb, SA",
    title: "Job title",
    sub: "Suburb, SA"
  }

Before and after comparison pairs belong in gallery/beforeandafterphotos/ and are added as .beforeafterpair blocks in gallery.html.
Best results: 4:3 ratio, around 1400px wide, compressed JPEG under 300KB.
